# CUSTOMER-SUPPORT-OPERATIONS-ANALYTICS-DASHBOARD
Customer Support Operations Analytics Dashboard

This project focused on building a customer support and operations analytics dashboard to monitor inquiry trends, response performance, customer satisfaction, and operational efficiency for Nye’s Lounge.

The dashboard included KPI tracking, customer support performance metrics, inquiry distribution analysis, and operational reporting visualizations using spreadsheet analytics and charting techniques. The objective was to provide actionable operational insights and improve customer support performance monitoring.


Tools Used
• Google Sheets
• Excel
• Pivot Tables
• Charts & Data Visualization
• Conditional Formatting
• Spreadsheet Functions


Key Tasks Performed
• Created customer support datasets
• Built KPI reporting dashboards
• Designed inquiry distribution charts
• Analyzed customer satisfaction trends
• Tracked response time performance
• Monitored operational ticket statuses


Findings
• Booking inquiries represented the highest inquiry category
• Faster response times correlated with higher customer satisfaction
• Complaint and refund inquiries required longer resolution periods
• Dashboard visibility improved operational monitoring


Recommendations
• Reduce customer response times for unresolved inquiries
• Implement escalation workflows for complaint handling
• Introduce customer feedback automation systems
• Improve ticket prioritization processes
